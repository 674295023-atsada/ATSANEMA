# MovieFree - ระบบสมัครสมาชิกดูหนังฟรีออนไลน์ (PHP + MySQL)

ระบบดูหนังและแอนิเมชันออนไลน์ฟรี พัฒนาด้วย PHP (PDO) + MySQL + Bootstrap 5

---

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

1. เปิดโปรแกรม **XAMPP Control Panel** และกด **Start** ที่โมดูล **Apache** และ **MySQL**
2. นำโฟลเดอร์ `movie_free` วางไว้ในไดเรกทอรี `C:\xampp\htdocs\movie_free`
3. เปิดเว็บเบราว์เซอร์แล้วไปที่:
   ```text
   http://localhost/movie_free/setup.php
   ```
   ระบบจะทำการเชื่อมต่อ MySQL สร้างฐานข้อมูล `movie_db`, ตารางข้อมูล, บัญชีผู้ดูแลระบบ และเพิ่มภาพยนตร์/แอนิเมชันตัวอย่าง 43 เรื่องให้อัตโนมัติทันที
4. หลังจากติดตั้งเสร็จ สามารถเข้าใช้งานหน้าหลักได้ที่:
   ```text
   http://localhost/movie_free/index.php
   ```

---

## 🔑 บัญชีเข้าสู่ระบบทดสอบ (Default Accounts)

| บทบาท (Role) | ชื่อผู้ใช้ (Username) | รหัสผ่าน (Password) | สิทธิ์การใช้งาน |
| :--- | :--- | :--- | :--- |
| **ผู้ดูแลระบบ (Admin)** | `admin` | `admin123` | เข้าถึง Admin Dashboard, จัดการสมาชิก, เพิ่ม/แก้ไข/ลบภาพยนตร์และแนวหนัง |
| **สมาชิกทั่วไป (User)** | `user1` | `user123` | รับชมภาพยนตร์, แก้ไขข้อมูลส่วนตัว, เปลี่ยนรหัสผ่าน |

## 📁 โครงสร้างไฟล์ในโปรเจกต์

```text
movie_free/
├── config.php            # ไฟล์ตั้งค่าการเชื่อมต่อฐานข้อมูล PDO MySQL
├── setup.php             # สคริปต์ติดตั้งฐานข้อมูลและลงข้อมูลตัวอย่างอัตโนมัติ
├── database.sql          # ไฟล์ SQL Dump สำหรับนำเข้าผ่าน phpMyAdmin
├── index.php             # หน้าหลัก คลังภาพยนตร์/แอนิเมชัน แถบเลื่อนสไลด์ด้านข้าง และปุ่มกรองประเภท
├── watch.php             # หน้าเล่นวิดีโอรับชมภาพยนตร์ (เฉพาะสมาชิกที่ล็อกอิน)
├── login.php             # หน้าเข้าสู่ระบบ (User / Admin) พร้อมปุ่มรูปตาดูรหัสผ่าน
├── register.php          # หน้าสมัครสมาชิก พร้อมปุ่มรูปตาดูรหัสผ่าน
├── profile.php           # หน้าแก้ไขข้อมูลสมาชิก และเปลี่ยนรหัสผ่าน
├── logout.php            # สคริปต์ออกจากระบบ
├── includes/
│   ├── auth_check.php    # ฟังก์ชันตรวจสอบ Session และ Guard ป้องกันสิทธิ์
│   ├── header.php        # ส่วนหัวเว็บไซต์ และ Navbar
│   └── footer.php        # ส่วนท้ายเว็บไซต์ และสคริปต์ปุ่มรูปตา
└── admin/
    ├── dashboard.php     # หน้าสรุปภาพรวม/สถิติ รายงานข้อมูล
    ├── users.php         # หน้าจัดการสมาชิก (ดู/แก้ไข/เปลี่ยนสิทธิ์/ลบ)
    └── movies.php        # หน้าจัดการภาพยนตร์ (เพิ่ม/แก้ไข/ลบ/เปลี่ยนแนวหนัง)
```

## ✨ ฟีเจอร์เด่นของระบบ

- **ระบบล็อกอินแยกสิทธิ์ (Role-based Authentication)**: สมาชิกทั่วไป และ ผู้ดูแลระบบ (Admin)
- **ปุ่มรูปตาเปิด/ซ่อนรหัสผ่าน (Password Visibility Toggle)**: ช่วยให้ผู้ใช้ดูรหัสผ่านที่กำลังพิมพ์ได้ทุกฟอร์ม
- **การจัดหมวดหมู่แบบเลื่อนสไลด์ด้านข้าง (Horizontal Scroll Carousel)**: แบ่งหมวดหมู่ `มาใหม่`, `แนะนำ`, `ยอดนิยม`, `ได้รางวัล`, `ทำเงิน`
- **แถบปุ่มเลือกประเภทสื่อ (Genre Filter)**: กรองตามประเภท เช่น *ครอบครัว, ไซไฟ, สยองขวัญ, ระทึกขวัญ, แอคชัน, แอนิเมชัน, โรแมนติก, คอมเมดี้, ดราม่า*
- **Admin Dashboard**: รายงานสถิติจำนวนสมาชิก สถิติจำนวนภาพยนตร์ และตารางกิจกรรมล่าสุด
- **Admin Movie Management**: จัดการภาพยนตร์และแก้ไขแนวหนังได้อย่างอิสระ
